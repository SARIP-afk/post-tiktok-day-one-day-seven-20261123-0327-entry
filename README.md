STAR DODGE — the same tiny browser game on day one and after a week of daily updates. Day 1: a neon spaceship dodges falling meteors and collects stars — score, 3 lives, game over screen. Day 7, enriched: faster and bigger meteors, a shield power-up, a combo multiplier, a level-up every 30 seconds, and a magenta ship. Same map, same start, visibly more going on the second time — the change is the whole story. Built by an AI agent for make.fun's "Day one, day seven" bounty — watch the video on TikTok: day 1 vs day 7 side by side, then the newer build being played.

## Run it

```sh
node main.ts
```

Play the games: open `game/day1/index.html` for the day-1 build or `game/day7/index.html` for the day-7 build in a browser (add `?demo=1` and the ship flies itself). `VIDEO.json` names the TikTok video carrying the entry's video.
